KOReader Progress Sync (KOSync)

Sync Engine

Sync your reading positions, percentage, and timestamps seamlessly between your Kindle / e-Reader and LightHouse.

1
Open any book in KOReader, tap the top of the screen to reveal the menu bar.
2
Tap the Tools (wrench icon) tab → select Progress sync.
3
Tap Custom sync server and enter server address:
Plain HTTP (Port 80) http://kosync-sg.wavypremium.xyz
Encrypted TLS (8443) https://kosync-sg.wavypremium.xyz:8443
Local LAN http://192.168.31.15:7200
4
Tap Login and enter Username: moe (password as configured).
5
Enable "Automatically keep documents in sync" for continuous background synchronization.
6
Tap Pull progress to this device now to verify synchronization with LightHouse.

KOReader & Kindle to Obsidian Highlight Sync

Obsidian Sync

Automatically synchronize your quotes, highlights, page numbers, chapters, and personal notes from KOReader and Kindle into structured Obsidian Markdown notes with YAML frontmatter, book synopsis, and live reading progress bars.

1 Native Joplin Clipper Exporter (Recommended — 1-Tap Wi-Fi Sync)
Native KOReader
1. In KOReader, open any book → tap top menu → Tools (wrench icon) → Export highlights.
2. Tap Choose formats and services → enable Joplin.
3. Tap Set Joplin IP and port number. KOReader's Joplin exporter is plain HTTP-only (no TLS).
Primary target (LAN HTTP):
192.168.31.15
Port: 8086
Optional WAN: opds.wavypremium.xyz plain HTTP port 80. ?token= travels in cleartext and is logged in proxy access logs. Do not publish the token.
4. Set JOPLIN_TOKEN in the uploader .env to a private random secret, then enter that same value in KOReader under Set authorization token. Do not use a shared or published token. If JOPLIN_TOKEN is unset, exports are rejected.
5. Tap Export now → Export to Joplin. Highlights, chapters, and notes are formatted with clean YAML frontmatter and saved to Books/<Title>.md. Re-exporting is 100% idempotent and never creates duplicate highlights!
2 Wireless Over-The-Air Export (KOReader Webhook / Export)
1. In KOReader, open any book → tap the top menu → Tools (wrench icon).
2. Select Export highlights → choose JSON or Markdown.
3. Point the export target / webhook to LightHouse:
http://192.168.31.15:8086/api/highlights/sync
Over public WAN (Singapore proxy):
https://reading-sg.wavypremium.xyz:8443/api/highlights/sync
4. Tap Export now. Highlights and notes are immediately written into your Obsidian vault at Books/<Title>.md.
3 CLI Batch & Continuous Watch Sync (bin/lighthouse sync-obsidian)
Plug in your Kindle / KOReader device or keep sidecar .sdr folders in Calibre:
bin/lighthouse sync-obsidian --apply
To keep auto-syncing continuously in background: bin/lighthouse sync-obsidian --apply --watch
Specify custom vault path: bin/lighthouse sync-obsidian --vault-path ~/Obsidian --apply
4 Type-C Kindle USB Two-Way Sync (Push Books & Pull Highlights)
USB-C
Plug your Kindle into MacBook Air or Mac Mini via USB-C. LightHouse auto-detects the device under /Volumes/, copies active/unread books from Calibre into books/ (or documents/), checks existing books across both directories to avoid re-copying, and pulls clippings & KOReader .sdr highlights directly into your Obsidian vault:
bin/lighthouse sync-kindle --apply
Dry-run preview: bin/lighthouse sync-kindle (or --dry-run)
Push full library: bin/lighthouse sync-kindle --apply --all
Auto-eject upon completion: bin/lighthouse sync-kindle --apply --eject
Prune device duplicates: bin/lighthouse sync-kindle --clean-duplicates (add --jev for cross-script & subtitle arbitration)
• Smart Ingestion & Duplicate Shield: Cross-script Burmese Unicode matching ([\u1000-\u109F]), byte size (±4KB) & title token signatures, normalizes leading index prefixes (01 - , Vol. 1 - ), reuses existing author/series folders, arbitrates ambiguous duplicates with Jev System-1, on-device duplicate cleaner (--clean-duplicates [--jev] or Web UI), and runs dot_clean to prevent macOS ._* ghost files.
5 Web Highlights & Quotes Viewer
Browse and copy all synced quotes, chapter markers, page numbers, and personal notes directly on the web app:
• Book Details Modal: Click any book card and tap the ✦ Highlights tab to view all synced quotes in translucent Apple Fluid cards with one-click copy buttons.
• Book Cards & Hover Expansion: Synced books display a subtle highlight indicator pill (✦ 12) on the cover and quote previews in the desktop hover wing panel.
• Developer API: GET /api/books/:id/highlights returns structured JSON quotes and notes.
6 Firecrawl On-Demand Web Article Scraper
On-Demand
Articles submitted via Web Uploader or Telegram Bot leverage the self-hosted Firecrawl cluster with an on-demand lifecycle to conserve host RAM:
• Wake on Demand: LightHouse automatically wakes Firecrawl containers via docker compose start in ~2.5s when an article ingestion request arrives.
• Auto-Sleep Idle Timer: After 15 minutes of inactivity without new scrapes, containers automatically shut down (docker compose stop), immediately releasing ~2.5 GB RAM back to macOS.
• Fail-Open Fallback: If Docker or Firecrawl is offline, article ingestion seamlessly falls back to direct browser fetch and Jina Reader.
• CLI Control: Manage cluster state manually via bin/lighthouse firecrawl status|up|down.
Idempotent Marker Preservation Guarantee
All extracted highlights are bounded by <!-- lighthouse:highlights:start --> and <!-- lighthouse:highlights:end -->. Any personal thoughts, reflections, or custom markdown sections you write outside these markers are completely preserved across repeated syncs.

Lnori & Elscione Light Novel Ingestion

Download and ingest light novel series or individual volumes directly from lnori.com and server.elsci.one / server.elscione.com via the Web UI (Upload Modal → Add Light Novel) or Telegram Bot. Links sent to the Telegram bot are enqueued to the centralized Uploader server queue (POST /api/lnori/ingest), reporting live queue positions, streaming active volume progress, and delivering completion cards with 1-tap Reading HQ buttons (also supported at POST /api/elscione/ingest). URLs with raw spaces, unencoded quotes, or missing protocol prefixes are automatically normalized. For Elscione, LightHouse automatically solves Anubis Proof-of-Work SHA-256 challenges, queries the _h5ai folder directory API, downloads EPUB volumes, extracts covers via sips, and enriches Calibre metadata.

Web Highlights & Quotes Viewer

Read and copy synced quotes, chapters, page numbers, and annotations directly on the web interface. Features translucent quote cards (blur(20px) saturate(180%)), amber accent markers, one-click quote copying with tactile checkmark feedback, highlight counter badges on book covers, and instant desktop hover quote previews.

USB-C Kindle Bulk Transfer & Safe Eject

Plug your Kindle e-reader into the Mac Mini via USB cable. LightHouse automatically detects the device (/Volumes/Kindle or /Volumes/KINDLE) and displays a live connection pill in the header. Tap the pill to open the Apple Fluid transfer modal, review available storage, select sync scope (Active & Unread vs All Books), preview pending transfer size, and execute one-click incremental synchronization of Calibre books directly into Kindle's books/ folder (or documents/, deeply scanning all subdirectories and filename variants, enforcing pre-flight storage verification, sanitizing FAT32 names, and supporting instant cancellation via Stop Sync). You can also send individual titles from the book details modal or safely unmount the device before unplugging.
